## 💡 Немного о Markdown

Markdown помогает красиво оформлять текст в README. Ниже показано, как пишутся команды и как они выглядят в итоге:

| Как писать (Код) | Как это выглядит (Результат) |
| :--- | :--- |
| `# Заголовок` | <h1>Заголовок</h1> |
| `**жирный текст**` | **жирный текст** |
| `*курсив*` | *курсив* |
| `- пункт` | <ul><li>пункт</li></ul> |
| `[Название](https://github.com)` | [Название](https://github.com) |
