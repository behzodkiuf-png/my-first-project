## 💡 Немного о Markdown

Markdown помогает красиво оформлять текст в README:

- `# Заголовок` создаёт заголовок;
- `**жирный текст**` выделяет важное;
- `*курсив*` добавляет акцент;
- `- пункт` создаёт список;
- `[название](ссылка)` добавляет ссылку.
